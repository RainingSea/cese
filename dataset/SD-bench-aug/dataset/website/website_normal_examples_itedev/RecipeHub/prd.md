## general overview of the project
The RecipeHub web application is designed to provide users with a platform to create, distribute, and manage their recipes through a user-friendly interface.

## software functional requirements
1. Users shall be able to view a welcome message and navigate to the Recipe Submission, Recipe Browsing, and User Profile Pages from the Home Page.
2. Users shall be able to submit a new recipe by entering a title, ingredients, and instructions on the Recipe Submission Page.
3. Users shall be able to see a success or error message upon submitting a recipe on the Recipe Submission Page.
4. Users shall be able to search for recipes by entering keywords on the Recipe Browsing Page.
5. Users shall be able to view the details of a recipe from the recipe list on the Recipe Browsing Page.
6. Users shall be able to navigate back to the Home Page from the Recipe Browsing Page using the Back to Home button.
7. Users shall be able to view their profile and list of submitted recipes on the User Profile Page.
8. Users shall be able to delete their account from the User Profile Page and return to the Login Page.
9. Users shall be able to view the full details of a recipe, including ingredients and instructions, on the Recipe Details Page.
10. Users shall be able to navigate back to the Home Page from the Recipe Details Page using the Back to Home button.
