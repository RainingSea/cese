# Software Description

### Objective

Medical Health Tracker is a software application that allows users to track and monitor their overall health and wellness. Users can input various health-related data such as daily activities, exercise routines, sleep patterns, nutrition intake, and stress levels. The software provides visualizations to help users analyze their health trends.

## Core Features
### Daily Activity Tracking
1. Allow users to input and categorize daily activities (e.g., work, leisure, physical activity).
2. Option to add custom activity types.
3. Include a timestamp for each activity to track patterns over time.
   
### Exercise Routine Logging
1. Record details of exercise routines, including type (e.g., cardio, strength training), duration, and intensity level.
2. Support for setting and tracking fitness goals.
3. Option to input calories burned and view weekly/monthly summaries.
   
### Sleep Pattern Monitoring
1. Log daily sleep data, including bedtime, wake-up time, and total sleep hours.
2. Provide a section for users to rate sleep quality (e.g., excellent, good, poor).
3. Visualize sleep trends to identify irregularities or improvements.
   
### Nutrition Intake Tracking
1. Allow users to input meals, snacks, and drinks consumed daily.
2. Include fields for calories, macronutrients (carbohydrates, proteins, fats), and water intake.
3. Support for generating daily or weekly summaries to analyze eating habits.

### Stress Level Monitoring
1. Provide a simple scale or slider to log daily stress levels (e.g., 1–10).
2. Allow users to add notes about the causes or triggers of stress.
3. Offer visualizations showing stress trends over time and correlation with other health factors.

### Health Trends Analysis and Visualizations
1. Generate charts and graphs for daily, weekly, and monthly trends in activities, exercise, sleep, nutrition, and stress.
2. Provide comparative insights, such as correlations between stress levels and sleep quality.
3. Allow users to export or save visualizations for offline use.

### Language

Use python to develop a application. You can use tkinter library to build graphical user interfaces.

### Data Storage

Data will be stored in local text files.
