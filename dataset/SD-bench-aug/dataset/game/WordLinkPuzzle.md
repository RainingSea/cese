# Software Description

## Objective

Design a puzzle game where players connect letters to form valid words.

## Core Features
### Word Formation Gameplay
1. Players can connect letters in any direction (horizontal, vertical, diagonal) to form valid words.
2. Include real-time word validation using a built-in dictionary.
3. Display a list of correctly formed words on the screen as the player progresses.

### Scoring System
1. Award points based on word length (e.g., short words earn fewer points, longer words earn more).
2. Bonus points for rare or complex words.
3. Provide a cumulative score tracker displayed prominently on the game screen.

## Language
Use python to develop a pygame application.

### Data Storage
Data will be stored in local text files.
