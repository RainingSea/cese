## general overview of the project
Develop a web application 'TravelRecommender' that provides personalized recommendations for travel destinations based on user preferences, such as budget, activities, and preferred climate.

## software functional requirements
1. User Registration
   - The system shall provide a Registration Page where users can create an account by entering a username and password.

2. User Login
   - The system shall provide a Login Page where users can log in to their account by entering their username and password.

3. Input Travel Preferences
   - The system shall allow users to input their travel preferences, including budget, preferred activities, and desired climate.

4. Generate Recommendations
   - The system shall generate a list of personalized travel destinations that match the user's preferences based on the input provided.

5. View Destination Details
   - The system shall provide detailed information about each recommended destination, including popular activities, climate, and travel costs.

6. Save Favorite Destinations
   - The system shall allow users to save their favorite destinations to a list for future reference.

7. User Logout
   - The system shall provide a logout functionality that returns users to the Login Page.
