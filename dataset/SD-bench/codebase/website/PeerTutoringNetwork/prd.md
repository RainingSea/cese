## general overview of the project
The objective of the PeerTutoringNetwork task is to develop a comprehensive web application using Python that facilitates peer-to-peer tutoring while storing all necessary information locally in text files.

## software functional requirements
1. **User Login**
   - The system shall provide a login page where users can enter their username and password to log in.

2. **User Registration**
   - The system shall provide a registration page for users to create a new account.
   - Users shall be able to create a new account by entering a username, password, and email on the registration page.

3. **Dashboard Access**
   - The system shall provide a dashboard that users can access after successfully logging in.

4. **View Tutors**
   - The dashboard shall include a "View Tutors" button that users can click to view available tutors.

5. **Request Tutoring**
   - The system shall allow users to request tutoring by filling out a form that includes the subject, details, and preferred date of tutoring.

6. **User Profile**
   - Users shall be able to access their profile page to view their username and email.

7. **User Logout**
   - The system shall provide a logout link on the dashboard and profile page for users to log out from the application.

8. **Contact Support**
   - The system shall provide a "Contact Us" page where users can fill out a contact form that includes their name, email, and message to contact the support team.

9. **Cancel Tutoring Request**
   - Users shall be able to cancel a tutoring request and return to the dashboard from the request tutoring page.
