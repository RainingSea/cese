## general overview of the project
Maze Escape Challenge is a puzzle game where players have to navigate through a maze to reach the exit. The maze is filled with obstacles and players must find the correct path by strategically moving through the maze. The game includes multiple levels of increasing difficulty, and players can track their progress and completion time.

## software functional requirements
1. The system shall generate a maze of varying sizes and difficulty for each new session.
2. The system shall allow players to navigate the maze using input controls (e.g., keyboard).
3. The maze shall contain walls and pathways that players must navigate through.
4. The system shall provide feedback upon reaching the exit, indicating completion of the maze.
5. The system shall track and display the time taken to complete the maze.
6. The system shall allow players to restart a level or return to the main menu during gameplay.
