## general overview of the project
Develop a Snake Game. You must design a GUI.

## software functional requirements
1. The system shall allow the player to control a snake on the screen using the arrow keys (up, down, left, right).
2. The system shall generate food that randomly appears on the screen for the snake to eat.
3. The system shall increase the length of the snake each time it eats food.
4. The system shall detect collisions between the snake and the walls of the screen, as well as collisions with the snake’s own body, and end the game if a collision occurs.
5. The system shall implement a scoring system that increases with each piece of food consumed, reflecting the current length of the snake.
6. The system shall increase the difficulty of the game as the snake grows longer, requiring the player to navigate more carefully.
7. The system shall provide a pause feature that allows the player to pause and resume the game, displaying the current score and a restart option in the pause menu.
8. The system shall display the final score when the game ends due to a collision with a wall or the snake’s body.
