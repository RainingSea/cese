## general overview of the project
Develop a Snake Game. You must design a GUI.

## software functional requirements
1. The system shall allow the player to control a snake on the screen using the arrow keys (up, down, left, right).
2. The system shall randomly generate food items on the screen for the player to eat.
3. The system shall increase the length of the snake each time the player consumes food.
4. The system shall detect collisions between the snake and the walls of the screen, as well as between the snake and its own body, and end the game if a collision occurs.
5. The system shall maintain a scoring system that increases with each piece of food consumed, reflecting the length of the snake.
6. The system shall increase the difficulty of the game as the snake grows longer, requiring the player to navigate around a larger body.
7. The system shall provide a pause feature that allows the player to pause and resume the game, displaying a pause menu with the current score and a restart option.
8. The system shall display the final score when the game ends due to a collision with the wall or the snake’s body.
