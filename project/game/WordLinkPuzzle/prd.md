## general overview of the project
Design a puzzle game where players connect letters to form valid words.

## software functional requirements
1. **Letter Connection**: The system shall allow players to connect letters on the screen to form valid words.

2. **Scoring System**: The system shall implement a scoring system that awards points based on the length of the words formed by the players.

3. **Timer**: The system shall include a timer that counts down during gameplay, adding a time constraint for players.

4. **Difficulty Levels**: The system shall provide different difficulty levels that players can select before starting the game, affecting the complexity of the letter arrangements.

5. **Progress Saving**: The system shall allow players to save their progress at any point during the game, enabling them to resume later.
