## general overview of the project
Block Connect is a puzzle game where players have to connect blocks of the same color to clear them from the board.

## software functional requirements
1. **Block Selection**: The system shall allow players to select blocks of the same color to initiate a connection.

2. **Grid Display**: The system shall display a grid containing blocks of various colors.

3. **Block Connection**: The system shall enable players to connect two or more blocks of the same color, resulting in those blocks disappearing from the board.

4. **Scoring System**: The system shall include a scoring system that tracks and displays the number of blocks cleared by the player.

5. **Block Fall Mechanism**: After blocks are cleared, the system shall automatically make the remaining blocks fall to occupy the empty spaces, and new blocks shall appear to fill the grid.

6. **Undo Move Functionality**: The system shall provide an option for players to undo their last move.
