## general overview of the project
Develop a Shape Shifter game where players rearrange geometric shapes (squares, triangles, circles) to match a target pattern.

## software functional requirements
1. The game must allow players to rearrange numbered tiles on a grid by sliding them horizontally or vertically.
2. The game must provide multiple difficulty levels, enabling players to choose the complexity of the puzzle.
3. The game must include a timer to track the time taken to solve the puzzle, displaying the time to the player.
4. The game must allow players to save their progress at any point, enabling them to resume from where they left off.
5. The game must provide hints to players when they request help, offering suggestions on possible moves to aid in solving the puzzle.
6. The game must shuffle the tiles at the start of a new game to create a random arrangement of the numbered tiles.
7. The game must confirm with players before saving progress to prevent unintentional saves.
8. The game must allow players to reset the puzzle to the initial shuffled state if they wish to restart.
9. The game must provide visual feedback when a tile is successfully slid into its correct position to indicate progress.
10. The game must include a user interface that clearly displays the current state of the puzzle, including the grid layout and available tiles.
