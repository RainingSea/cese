## general overview of the project
Develop a Space Invaders game. You must design a GUI.

## software functional requirements
1. The system shall allow the player to control a spaceship at the bottom of the screen using the left and right arrow keys for movement.
2. The system shall enable the player to shoot lasers using the spacebar.
3. The system shall implement alien enemies that descend from the top of the screen, which the player must destroy by shooting them with the spaceship's lasers.
4. The system shall allow alien enemies to move horizontally across the screen and gradually descend lower with each movement.
5. The system shall implement projectiles fired by alien enemies from the top of the screen that the player must avoid.
6. The system shall end the game if the player is hit by an alien enemy's projectile.
7. The system shall allow the player to destroy enemy projectiles by shooting them or avoiding them.
8. The system shall end the game when all enemies are destroyed or when the player is hit by an alien projectile.
