## general overview of the project
Develop a Space Invaders game. You must design a GUI.

## software functional requirements
1. The system shall allow the player to control a spaceship at the bottom of the screen using the left and right arrow keys for movement.
2. The system shall allow the player to shoot lasers using the spacebar.
3. The system shall display alien enemies that descend from the top of the screen.
4. The system shall allow the player to destroy alien enemies by shooting them with the spaceship's lasers.
5. The system shall implement horizontal movement for alien enemies, which gradually descend lower with each movement.
6. The system shall allow the player to avoid being hit by alien enemies' projectiles fired from the top of the screen.
7. The system shall end the game if the player is hit by an alien projectile.
8. The system shall allow the player to destroy enemy projectiles by shooting them or avoiding them.
9. The system shall end the game when all enemies are destroyed or the player is hit by an alien projectile.
