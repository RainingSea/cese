## general overview of the project
Develop a Color Swap Challenge game. You must design a GUI.

## software functional requirements
1. The system shall allow the player to control a grid of colored blocks, enabling them to swap adjacent blocks.
2. The system shall provide an objective for the player to clear the board by eliminating a specified number of blocks within a limited number of moves.
3. The system shall automatically clear matches when three or more blocks of the same color are aligned either horizontally or vertically.
4. The system shall include multiple levels, each with increasing difficulty, featuring larger grids, more complex block arrangements, and additional color types.
5. The system shall allow players to earn bonus points by creating combos, which involve clearing multiple matches in a single move, or by activating power-ups that clear blocks in specific patterns.
6. The system shall track the number of moves used by the player to complete each level and enforce a move limit for level completion.
7. The system shall provide power-ups that can be used strategically to assist in clearing the board, and players shall have the ability to earn or unlock new power-ups as they progress through the game.
8. The system shall implement a scoring system that calculates points based on the number of blocks cleared, combos achieved, and the number of moves used to complete each level.
