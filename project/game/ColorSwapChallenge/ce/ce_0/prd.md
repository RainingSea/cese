## general overview of the project
Develop a Color Swap Challenge game. You must design a GUI.

## software functional requirements
1. The player must be able to control a grid of colored blocks and swap adjacent blocks.
2. The game must allow the player to create matches of three or more blocks of the same color.
3. The game must automatically clear matches when three or more blocks of the same color are aligned horizontally or vertically.
4. The game must include multiple levels with increasing difficulty, featuring larger grids, more complex block arrangements, and additional color types.
5. The game must provide players with the ability to earn bonus points by creating combos or activating power-ups.
6. The game must track the number of moves used to complete each level and enforce a move limit for level completion.
7. The game must allow players to use power-ups strategically to help clear the board and provide a mechanism for earning or unlocking new power-ups as they progress.
8. The game must feature a scoring system that calculates points based on the number of blocks cleared, combos achieved, and the number of moves used to complete each level.
