## general overview of the project
Color Link Puzzle is a puzzle game where players have to connect adjacent blocks of the same color to clear them from the grid. The objective is to create links by dragging a line from one block to another of the same color, ensuring that the path between them is not blocked by other blocks. The game includes multiple levels with increasing difficulty, bonuses, and power-ups to enhance gameplay.

## software functional requirements
1. Players must be able to connect adjacent blocks of the same color by dragging a line between them.
2. The system must clear connected blocks from the grid once they are linked.
3. The game must include multiple levels that increase in difficulty as the player progresses.
4. A scoring system must be implemented to track the player’s performance throughout the game.
5. The system must provide visual feedback to the player when blocks are successfully cleared.
6. Connections between blocks can only be made if the path between them is unobstructed by other blocks.
7. A basic menu must be available for players to start a new game and view high scores.
