## general overview of the project
Develop a Treasure Hunt game. You must design a GUI.

## software functional requirements
1. The game must allow the player to control a character within a maze to find a hidden treasure.
2. The maze must consist of walls and paths, with the treasure placed at a random location for each level.
3. The player must be able to move the character up, down, left, or right using the arrow keys or WASD keys.
4. The game must track the time taken by the player to find the treasure, and the player's score must increase with each successful treasure find.
5. Upon finding the treasure, the player must be transported to a new maze that is more complex and contains additional obstacles.
6. The game must enforce a time limit for each level, and it must end if the player fails to find the treasure within that time.
7. A timer must be displayed to the player, tracking the duration taken to find the treasure, and the best time must be saved for the player.
8. The player must have the option to restart the game after completing a level or upon losing the game.
