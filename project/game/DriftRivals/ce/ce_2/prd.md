## general overview of the project
Develop a Drift Rivals game. You must design a GUI.

## software functional requirements
1. The system shall allow the player to control a drift car using the keyboard's arrow keys (up, down, left, right) or a game controller.
2. The system shall provide a variety of static tracks designed to challenge the player's drifting skills.
3. The system shall enable players to compete in drift challenges with the objective of earning the highest score by executing precise and stylish drifts around corners.
4. The system shall implement a scoring system that calculates scores based on drift precision, speed, and style as the player drifts through the track.
