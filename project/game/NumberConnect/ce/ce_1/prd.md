## general overview of the project
Develop a Number Connect game. You must design a GUI.

## software functional requirements
1. The system shall allow the player to connect numbers in a sequence to form a continuous path.
2. The system shall display a game board consisting of a grid of numbered tiles.
3. The system shall require the player to connect the tiles in numerical order, starting from the first number.
4. The system shall restrict player movement to only horizontal or vertical directions to adjacent tiles, disallowing diagonal movements.
5. The system shall ensure that the path forms a continuous line without breaking, and the player shall not be able to revisit any tile once it has been used.
6. The system shall provide multiple levels with increasing difficulty, where the grid size and number of tiles increase.
7. The system shall include a timer to challenge players to complete the path within a certain time.
