## general overview of the project
Develop a Gem Blast game. You must design a GUI.

## software functional requirements
1. The game shall allow the player to control a grid of gems and swap adjacent gems to create matches of three or more gems of the same color.
2. The game shall have an objective for the player to clear the board by eliminating gems in matches of three or more.
3. The game board shall consist of a grid, and the player shall be able to swap gems horizontally or vertically to create valid matches.
4. The game shall automatically clear matches when three or more gems of the same color are aligned, and new gems shall fall into the grid to replace the cleared ones.
5. The game shall award points to the player for each match made, with higher scores for larger matches (e.g., four or more gems).
6. The game shall include a timer limit to challenge players to complete the level within certain constraints.
7. The game shall allow players to earn bonus points through combos or chain reactions, where multiple matches occur in one move.
8. The game shall include multiple levels with increasing difficulty, where the grid size may grow and more complex gem patterns appear.
9. The game shall provide an option for the player to reset the game to start over or try a different level.
