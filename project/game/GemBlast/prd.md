## general overview of the project
Develop a Gem Blast game. You must design a GUI.

## software functional requirements
1. The system shall allow the player to control a grid of gems, enabling them to swap adjacent gems to create matches of three or more gems of the same color.
2. The system shall provide an objective for the player to clear the board by eliminating gems in matches of three or more.
3. The system shall display a game board consisting of a grid where players can swap gems horizontally or vertically to create valid matches.
4. The system shall automatically clear matches when three or more gems of the same color are aligned and shall allow new gems to fall into the grid to replace the cleared ones.
5. The system shall calculate and display points earned for each match made, with higher scores awarded for larger matches (e.g., four or more gems).
6. The system shall implement a timer limit to challenge players to complete the level within certain constraints.
7. The system shall allow players to earn bonus points through combos or chain reactions, where multiple matches occur in one move.
8. The system shall include multiple levels with increasing difficulty, where the grid size may grow and more complex gem patterns appear.
9. The system shall provide an option for the player to reset the game to start over or try a different level.
