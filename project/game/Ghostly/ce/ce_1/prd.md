## general overview of the project
Develop a Ghostly game. You must design a GUI.

## software functional requirements
1. The player must be able to control a ghost using the arrow keys for movement.
2. The game must include walls that the ghost cannot pass through.
3. The ghost must be able to eat pellets and superpellets (big pellets) to gain special abilities.
4. When the ghost eats a superpellet, it must gain the ability to eat other ghosts, causing them to disappear.
5. The game must prevent the player’s ghost from colliding with another ghost without the superpellet power-up, resulting in an invalid move similar to hitting a wall.
6. After 50 game ticks, a monster must be activated at position [1,1] to chase the player's ghost.
7. The game must end if the monster collides with the player's ghost.
8. The game must end if the player's ghost collides with a monster or another ghost without the power-up.
