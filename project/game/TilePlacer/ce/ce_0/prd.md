## general overview of the project
Design a board game where players place tiles to create patterns and earn points. The game is turn-based and can be played by multiple players or against AI.

## software functional requirements
1. The game shall display a board and available tiles for players to choose from.
2. The game shall allow players to select and place tiles on the board during their turn.
3. The game shall calculate and display points based on predefined pattern rules after each turn.
4. The game shall support multiplayer turns, allowing multiple players to take their turns in sequence.
5. The game shall provide an option for players to undo their last action.
6. The game shall automatically save progress to allow players to resume later.
7. The game shall allow players to customize settings, including tile colors and board design.
