## general overview of the project
Develop a basic two-player Gomoku game.

## software functional requirements
1. **Game Board Setup**
   - The game board must be visually represented as a grid divided by black intersecting vertical and horizontal lines.
   - The background color of the board must be orange yellow.

2. **Player Assignment**
   - Players must be assigned either black or white pieces for the game.

3. **Piece Placement**
   - Both players must use the left mouse button to place their pieces on the board.
   - The game must allow piece placement only on empty grid squares.

4. **Victory Condition**
   - The game must detect when one player achieves victory by aligning five of their pieces in a row (horizontally, vertically, or diagonally).
   - Upon a victory, the game must prevent further piece placements on the board.
   - The game must display the winning player's information on the board.
