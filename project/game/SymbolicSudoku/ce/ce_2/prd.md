## general overview of the project
Develop a Symbolic Sudoku Challenge game. You must design a GUI.

## software functional requirements
1. The system shall allow the player to fill a 9x9 grid with symbols from a given set, such as numbers, letters, or shapes.
2. The system shall enforce the standard Sudoku rules, ensuring that each row, column, and 3x3 subgrid contains all the symbols exactly once.
3. The system shall provide multiple difficulty levels, including easy, medium, and hard, which will vary based on the initial placement of symbols and the complexity of the puzzle.
4. The system shall enable players to input symbols into empty cells using either mouse clicks or keyboard input.
5. The system shall track the time taken to solve each puzzle and provide a feature for players to challenge themselves to beat their previous time.
6. The system shall allow the player to reset the puzzle to start over or select a new puzzle from the same or a different difficulty level.
