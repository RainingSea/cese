## general overview of the project
Random_Password_Generator is a software application that generates random passwords based on user-specified parameters such as length and character types. The user can specify the inclusion/exclusion of characters like uppercase letters, lowercase letters, numbers, and symbols. It also provides an option to exclude ambiguous characters for improved password readability.

## software functional requirements
1. The system shall allow users to specify the desired password length.
2. The system shall enable users to select the inclusion or exclusion of uppercase letters.
3. The system shall enable users to select the inclusion or exclusion of lowercase letters.
4. The system shall enable users to select the inclusion or exclusion of numbers.
5. The system shall enable users to select the inclusion or exclusion of symbols.
6. The system shall provide an option for users to exclude ambiguous characters.
7. The system shall generate random passwords based on the user specifications.
