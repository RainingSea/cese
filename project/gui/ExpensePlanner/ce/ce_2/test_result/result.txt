```plaintext
    FUNCTION add_expense(amount: float, category: str, date: str, description: str):
        CREATE expense = Expense(amount, category, date, description)
        APPEND expense TO self.expenses
        CALL save_expenses()

    FUNCTION load_expenses() RETURNS List[Expense]:
        TRY:
            OPEN 'expenses.json' FOR READ AS file:
                LOAD JSON from file INTO data
                RETURN [Expense constructed from item FOR item IN data]
        EXCEPT FileNotFoundError:
            RETURN []
    
    FUNCTION save_expenses():
        OPEN 'expenses.json' FOR WRITE AS file:
            DUMP [variables of expense FOR expense IN self.expenses] INTO JSON format INTO file
```

- The code manages expenses through the `ExpenseManager` class, allowing users to add expenses that are represented by the `Expense` class.
