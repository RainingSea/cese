## general overview of the project
The Knowledge Tracker software is designed to help users track and organize their scientific knowledge. The software allows users to input, categorize, and store various pieces of scientific information, such as theories, concepts, and experiments. It provides features for easy retrieval, organization, and updating of knowledge, helping users maintain their learning and research.

## software functional requirements
1. The system shall allow users to input scientific knowledge, including theories, concepts, and experiments.
2. The system shall provide users with a user-friendly interface to categorize the inputted scientific knowledge.
3. The system shall enable users to easily access and retrieve stored scientific knowledge.
4. The system shall allow users to update existing scientific knowledge.
5. The system shall provide functionality for users to add new scientific knowledge over time.
6. The system shall store all scientific knowledge in local text files for data persistence.
