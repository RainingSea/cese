```
CLASS KnowledgeTracker:
    
    FUNCTION __init__():
        DECLARE theories AS self.retrieve_theories()
        DECLARE concepts AS self.retrieve_concepts()
        DECLARE experiments AS self.retrieve_experiments()
    
    FUNCTION add_theory(entry: STRING):
        APPEND entry TO theories
        CALL _save_to_file('theories.txt', theories)

    FUNCTION add_concept(entry: STRING):
        APPEND entry TO concepts
        CALL _save_to_file('concepts.txt', concepts)

    FUNCTION add_experiment(entry: STRING):
        APPEND entry TO experiments
        CALL _save_to_file('experiments.txt', experiments)

    FUNCTION retrieve_theories() -> LIST:
        RETURN CALL _load_from_file('theories.txt')

    FUNCTION retrieve_concepts() -> LIST:
        RETURN CALL _load_from_file('concepts.txt')

    FUNCTION retrieve_experiments() -> LIST:
        RETURN CALL _load_from_file('experiments.txt')

    FUNCTION _load_from_file(filename: STRING) -> LIST:
        IF os.path.exists(filename):
            OPEN filename AS file:
                RETURN [line.strip() FOR line IN file.readlines()]
        RETURN []

    FUNCTION _save_to_file(filename: STRING, data: LIST):
        OPEN filename FOR writing AS file:
            FOR entry IN data:
                WRITE entry + "\n" TO file

```

**Key Functionality and Libraries:**
- The project utilizes the `os` library to check file existence before loading data and to handle file operations.
- The KnowledgeTracker class is designed to manage scientific knowledge by providing functionalities to add, retrieve, and store theories, concepts, and experiments, allowing users to categorize scientific knowledge easily.
