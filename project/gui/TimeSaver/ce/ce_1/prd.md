## general overview of the project
Time Saver is a user-friendly shopping software application that allows users to create and manage shopping lists effortlessly. Users can easily add items to the list, categorize them, and set reminders for upcoming shopping trips. The software provides a simple and intuitive user interface, making it easy for users to stay organized and never forget essential items while shopping. With Time Saver, users can save time and streamline their shopping experience.

## software functional requirements
1. The system shall allow users to create new shopping lists.
2. The system shall allow users to manage existing shopping lists, including editing and deleting lists.
3. The system shall allow users to add items to their shopping lists.
4. The system shall allow users to categorize items within their shopping lists.
5. The system shall allow users to set reminders for upcoming shopping trips.
6. The system shall provide an intuitive and simple user interface for easy navigation.
7. The system shall allow users to view their shopping lists in a clear and organized manner.
8. The system shall ensure that all data is stored in local text files for persistence.
