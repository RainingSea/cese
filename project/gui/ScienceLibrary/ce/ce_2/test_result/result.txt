```pseudocode
CLASS AnnotationManager
    FUNCTION __init__()
        LOAD annotations from 'annotations.txt' into self.annotations

    FUNCTION create_annotation(article: STRING, note: STRING)
        IF article NOT IN self.annotations
            INITIALIZE self.annotations[article] as empty list
        APPEND note to self.annotations[article]
        CALL save_annotations()

    FUNCTION load_annotations() RETURNS DICTIONARY
        TRY
            OPEN 'annotations.txt' AS file
            INITIALIZE annotations as empty dictionary
            FOR each line IN file
                SPLIT line by '|'
                SET article = part before '|'
                SET note = part after '|'
                
                IF article IN annotations
                    APPEND note to annotations[article]
                ELSE
                    INITIALIZE annotations[article] as list containing note
            RETURN annotations
        CATCH FileNotFoundError
            RETURN empty dictionary

    FUNCTION save_annotations()
        OPEN 'annotations.txt' FOR writing
        FOR each article, notes in self.annotations
            FOR each note IN notes
                WRITE article + '|' + note to file
```

**Key Functionality:**
- Manages annotations for articles by loading, creating, and saving them to a text file.
- Uses basic file handling (open, read, write) in Python.
