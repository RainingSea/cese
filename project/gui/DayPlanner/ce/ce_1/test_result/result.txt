```python
CLASS Main:
    FUNCTION __init__():
        INITIALIZE task_manager as TaskManager()
        INITIALIZE root as tk.Tk()
        SET root title to "Day Planner"
        CALL create_widgets()

    FUNCTION create_widgets():
        CREATE task_name_entry as Entry in root
        CREATE priority_var as StringVar with default value "Medium"
        CREATE OptionMenu for priority selection
        CREATE category_var as StringVar with default value "Work"
        CREATE OptionMenu for category selection
        CREATE start_time_entry as Entry in root
        CREATE end_time_entry as Entry in root
        CREATE save_button with command linked to save_task()
        CREATE display_area as Text in root
        CALL display_tasks()

    FUNCTION save_task():
        name = task_name_entry input
        priority = priority_var value
        category = category_var value
        start_time = start_time_entry input
        end_time = end_time_entry input

        IF name is empty OR start_time is empty OR end_time is empty:
            CALL messagebox.showerror with "Input Error"
            RETURN

        CALL task_manager.add_task(name, priority, category, start_time, end_time)
        CALL display_tasks()
        CALL clear_entries()

    FUNCTION display_tasks():
        CLEAR display_area content
        FOR each task in task_manager.tasks:
            INSERT task details into display_area with formatted string

    FUNCTION clear_entries():
        CLEAR task_name_entry
        RESET start_time_entry to "Start Time (HH:MM)"
        CLEAR end_time_entry and SET to "End Time (HH:MM)"

    FUNCTION main():
        CALL root.mainloop()

IF __name__ == "__main__":
    CREATE app as Main()
    CALL app.main()

CLASS TaskManager:
    FUNCTION __init__():
        INITIALIZE tasks as empty List[Task]
        CALL load_tasks()

    FUNCTION add_task(name, priority, category, start_time, end_time):
        CREATE new_task as Task with given parameters
        APPEND new_task to tasks
        CALL save_tasks()

    FUNCTION load_tasks():
        IF 'tasks.txt' exists:
            OPEN 'tasks.txt' for reading
            FOR each line in file:
                SPLIT line content and CREATE Task
                APPEND task to tasks

    FUNCTION save_tasks():
        OPEN 'tasks.txt' for writing
        FOR each task in tasks:
            WRITE formatted task data to file
```

**Key Functionality:**
- The `Main` class sets up a GUI for task management using the `tkinter` library, allowing users to input, prioritize, categorize, and visualize daily tasks.
- The `TaskManager` class manages a list of tasks, including adding, loading, and saving tasks to a text file. It utilizes file handling to maintain task persistence.

**Special Libraries:**
- `tkinter`: A standard Python interface for creating graphical user interfaces, enabling the application to gather user input and display task information visually.
