## general overview of the project
Time Tracker is a software application that helps users effectively track and manage their time. It provides features such as task creation, timers, and alarms to enhance productivity. Detailed reports help users gain insights into their time allocation, enabling them to identify areas for improvement and optimize productivity.

## software functional requirements
1. The system shall allow users to create tasks with a title and description.
2. The system shall enable users to set timers for each task, allowing them to track the duration of the task.
3. The system shall provide functionality for users to set alarms for reminders related to tasks.
4. The system shall generate detailed reports on time allocation for tasks, displaying the time spent on each task.
5. The system shall provide insights based on the generated reports to help users improve their time management skills.
