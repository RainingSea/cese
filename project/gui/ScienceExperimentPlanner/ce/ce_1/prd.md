## general overview of the project
Science_Experiment_Planner is a software application designed to assist science students and researchers in planning and organizing their experiments. The software allows users to input experiment details, including objectives, materials, procedures, and expected results. It also enables users to track the progress of their experiments and record observations, helping ensure experiments are well-organized and executed effectively.

## software functional requirements
1. The system shall allow users to input and organize experiment details, including:
   - Objectives of the experiment
   - List of materials required
   - Step-by-step procedures for conducting the experiment

2. The application shall provide functionality for users to track the progress of ongoing experiments, including:
   - Status updates (e.g., Not Started, In Progress, Completed)
   - Ability to mark specific steps as completed

3. Users shall be able to record observations and results during and after experiments, which includes:
   - Input fields for entering observations
   - Sections for documenting results and conclusions

4. The application shall provide a user-friendly interface for managing multiple experiments, which includes:
   - A dashboard displaying all experiments
   - Options to create, edit, and delete experiments
   - Navigation tools to switch between different experiments easily
