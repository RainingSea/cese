## general overview of the project
Notepad Plus is a software application that provides an enhanced text editing experience. It includes features such as syntax highlighting, code indentation, search and replace functionality, and customizable themes. Notepad Plus allows users to create and edit text files with ease, making it a versatile tool for programmers, writers, and anyone who needs a powerful yet simple text editor.

## software functional requirements
1. The application shall enable users to create new text files.
2. The application shall allow users to edit existing text files.
3. The application shall provide syntax highlighting for various programming languages, allowing users to easily read and write code.
4. The application shall offer code indentation features to help users format their code properly.
5. The application shall provide a search functionality that allows users to find specific text within their documents.
6. The application shall provide a replace functionality that allows users to replace specific text with new text within their documents.
7. The application shall offer customizable themes, enabling users to change the appearance of the text editor according to their preferences.
