```pseudocode
CLASS TextEditor
    FUNCTION __init__()
        INITIALIZE content as empty string
        INITIALIZE window as new tk.Tk() instance
        SET window title to "Simple Text Editor"
        CALL create_widgets()  // Function to set up GUI components

    FUNCTION create_widgets()
        CREATE text_area as new tk.Text instance with word wrapping
        PACK text_area to expand and fill the window
        CREATE menu_bar as new tk.Menu instance
        CONFIGURE window menu to menu_bar

        CREATE file_menu and add commands: "New", "Open", "Save"
        ADD file_menu to menu_bar as "File"
        CREATE edit_menu and add commands: "Search", "Replace"
        ADD edit_menu to menu_bar as "Edit"
        CREATE theme_menu and add command: "Set Theme"
        ADD theme_menu to menu_bar as "Theme"

    FUNCTION search()
        PROMPT user with simpledialog for "Enter text to search:"
        IF query is not None
            GET content from text_area
            FIND all matches of query in content using regex
            SHOW message box with the number of matches found

    FUNCTION run()
        CALL window.mainloop()  // Start the GUI loop
```

**Key Functionality:**
- Utilizes the `tkinter` library to create a GUI text editor.
- The search functionality allows users to input a string and checks the text area's content for matches, providing feedback via a message box.
