## general overview of the project
BMI Calculator is a health tool that helps users calculate their Body Mass Index (BMI) based on their weight and height.

## software functional requirements
1. The system shall provide an input interface for users to enter their weight and height.
2. The system shall calculate the BMI using the formula: BMI = weight (kg) / (height (m) * height (m)).
3. The system shall classify the calculated BMI into categories: underweight, normal, overweight, and obese.
4. The system shall display an interpretation of the user's BMI based on the calculated value.
5. The system shall provide recommendations for improvement based on the user's BMI category.
