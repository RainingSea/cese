## general overview of the project
BMI Calculator is a health tool that helps users calculate their Body Mass Index (BMI) based on their weight and height.

## software functional requirements
1. The application shall provide an input field for users to enter their weight.
2. The application shall provide an input field for users to enter their height.
3. The application shall calculate the BMI using the formula: BMI = weight (kg) / (height (m) * height (m)).
4. The application shall display the calculated BMI result to the user.
5. The application shall classify the calculated BMI into categories: underweight, normal, overweight, and obese.
6. The application shall provide an interpretation of the user's BMI based on the calculated value.
7. The application shall provide recommendations for improvement based on the user's BMI category.
