## general overview of the project
Countdown_Timer is a software application that allows users to set a specific amount of time and countdown to zero.

## software functional requirements
1. The system shall provide a user interface that allows users to input a specific amount of time for the countdown.
2. The system shall allow users to start the countdown once the time has been set.
3. The system shall display the countdown timer visually on the user interface.
4. The system shall automatically decrement the time displayed on the countdown timer until it reaches zero.
5. The system shall provide an option to reset the timer to allow users to set a new countdown duration.
6. The system shall save the last used countdown duration in a local text file for future reference.
