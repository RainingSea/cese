## general overview of the project
CalculationAssistant is an intuitive software application that assists users in performing various calculations quickly and accurately. It supports basic arithmetic operations as well as more advanced functions like square root, exponentiation, and percentage calculation.

## software functional requirements
1. The application shall allow users to perform basic arithmetic operations, including:
   - Addition
   - Subtraction
   - Multiplication
   - Division

2. The application shall provide functionality to calculate square roots of given numbers.

3. The application shall enable users to perform exponentiation calculations, allowing them to raise numbers to specified powers.

4. The application shall include a feature to calculate percentages based on user input.
