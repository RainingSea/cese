## general overview of the project
The Data Summarizer is a software application that provides users with a summary of their data sets. It analyzes the data and generates key insights, such as the mean, median, mode, and range for numerical data, and the frequency and distribution for categorical data. Users can easily import their data, choose the variables they want to analyze, and view the generated summary.

## software functional requirements
1. The system shall allow users to import data sets into the application.
2. The system shall analyze numerical data to calculate the mean.
3. The system shall analyze numerical data to calculate the median.
4. The system shall analyze numerical data to calculate the mode.
5. The system shall analyze numerical data to calculate the range.
6. The system shall analyze categorical data to determine the frequency.
7. The system shall analyze categorical data to determine the distribution.
8. The system shall allow users to choose variables for analysis.
9. The system shall display the generated summary of the data.
