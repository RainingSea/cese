## general overview of the project
Time_Converter is a software application that enables users to convert time between different time zones and formats.

## software functional requirements
1. The system shall provide a user interface that allows users to input a time value.
2. The system shall allow users to select the source time zone from which they want to convert.
3. The system shall allow users to select the target time zone to which they want to convert the time.
4. The system shall display the converted time in the selected target time zone.
5. The system shall allow users to select a time format (e.g., 12-hour or 24-hour format) for the input and output times.
6. The system shall convert the input time to the selected format and display it accordingly.
7. The system shall save user preferences for time zones and formats in local text files for future use.
8. The system shall provide error handling for invalid time inputs or unsupported time zones.
