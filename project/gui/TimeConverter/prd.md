## general overview of the project
Time_Converter is a software application that enables users to convert time between different time zones and formats.

## software functional requirements
1. The system shall allow users to select a source time zone from a list of available time zones.
2. The system shall allow users to select a target time zone from a list of available time zones.
3. The system shall provide an input field for users to enter the time they wish to convert.
4. The system shall convert the entered time from the source time zone to the target time zone and display the result to the user.
5. The system shall allow users to select a time format (e.g., 12-hour or 24-hour format) for the input and output times.
6. The system shall convert the entered time into the selected format and display the result to the user.
7. The system shall save the user's conversion history in a local text file for future reference.
8. The system shall provide an option for users to clear their conversion history.
