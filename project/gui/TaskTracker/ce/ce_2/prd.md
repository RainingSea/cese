## general overview of the project
The Office Task Tracker is a software designed to help users efficiently track and manage their tasks within an office setting. It provides a user-friendly interface for creating and organizing tasks, setting deadlines, assigning priority levels, and tracking progress. Users can easily add new tasks, update task details, and mark tasks as complete. The software also includes features such as task categorization, search functionality.

## software functional requirements
1. Users shall be able to create, organize, and manage tasks.
   - The system shall provide an interface for users to input task details including title, description, and status.
   - Users shall be able to edit existing tasks.
   - Users shall be able to delete tasks.

2. The application needs to allow users to set deadlines and assign priority levels for tasks.
   - Users shall be able to specify a deadline for each task.
   - Users shall be able to assign priority levels (e.g., high, medium, low) to tasks.

3. Users shall be able to track the progress of their tasks.
   - The system shall allow users to update the status of tasks (e.g., not started, in progress, completed).
   - Users shall be able to view a summary of task progress.

4. The application needs to support task categorization for better organization.
   - Users shall be able to categorize tasks into predefined categories (e.g., work, personal, urgent).
   - The system shall allow users to create custom categories.

5. Users shall be able to search for specific tasks.
   - The application shall provide a search functionality that allows users to find tasks by title or keywords.
   - Users shall be able to filter search results based on categories or priority levels.
