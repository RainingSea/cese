#### Issue Identification:
The error indicates that when the line is read from the file, there are not enough values. Given the content of `tasks.txt`:

```

Task 2|Description for task 2|2023-10-12|Medium|Incomplete
Task 3|Description for task 3|2023-10-15|Low|Complete
```

The delimiter used in `tasks.txt` is a pipe (`|`), but the `load_tasks` method is expecting commas (`,`). Thus, when it tries to split the line using a comma, it ends up treating the entire line as a single element.

#### Solution:
Change the splitting character in the `load_tasks` function from a comma to a pipe:
```python

```
