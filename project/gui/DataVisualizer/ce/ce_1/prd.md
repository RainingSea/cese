## general overview of the project
The Data Visualizer is a software application that allows users to create visually appealing and interactive visualizations of their data sets. It provides a wide range of visualization options, including bar charts, line graphs, scatter plots, and pie charts. Users can easily import their data, choose the appropriate visualization type, customize the appearance of the visualization, and export the final visualization as an image.

## software functional requirements
1. The application shall allow users to import data sets into the application.
2. The application shall provide functionality to create visualizations, including but not limited to bar charts, line graphs, scatter plots, and pie charts.
3. The application shall enable users to choose the appropriate type of visualization based on the imported data.
4. The application shall allow users to customize the appearance of the visualizations, including options for colors, labels, and titles.
5. The application shall provide an option to export the visualization as an image file.
