  - **Suggestions:** Implement necessary UI components (buttons for adding/editing/deleting notes) and ensure feedback is provided when actions are performed (e.g., confirming a note addition or deletion). - **Problem 3:** Data storage and organization are minimal.
  - **Suggestions:** Although using plain text files, consider organizing notes in a structured way.   - Input fields for adding new notes and editing existing ones. 
  - Buttons for actions like "Add Note," "Edit Note," and "Delete Note."
  - Drop-down menus for sorting options should be added to enhance functionality.

- **Data Storage:** Ensure that each notebook text file is consistently structured (i.e., each note represented with delimiters) to facilitate easy reading and writing.
