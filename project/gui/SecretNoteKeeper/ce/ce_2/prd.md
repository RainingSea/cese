## general overview of the project
Secret Note Keeper is a software application that allows users to securely store and manage their private notes. It provides encryption features to ensure the confidentiality of the notes, and users can create multiple notebooks to categorize their notes based on topics or themes. The software allows users to add, edit, and delete notes within each notebook, and supports features like search and sorting for easy retrieval of specific notes.

## software functional requirements
1. The system shall allow users to create multiple notebooks for categorizing their private notes.
2. The system shall provide encryption features to ensure the confidentiality of the notes stored by users.
3. The system shall allow users to add new notes to each notebook.
4. The system shall allow users to edit existing notes within each notebook.
5. The system shall allow users to delete notes from each notebook.
6. The system shall support search functionality to enable users to retrieve specific notes based on keywords.
7. The system shall support sorting of notes within each notebook for easier organization and retrieval.
