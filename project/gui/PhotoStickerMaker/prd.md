## general overview of the project
PhotoStickerMaker is a software that allows users to create customized stickers using their own photos. Users can select an image, choose the desired shape and size of the sticker, and add text or decorative elements. The software provides easy-to-use tools for cropping, resizing, and adding effects to the photos. Once the sticker is created, users can save it as a transparent PNG file to use in messaging apps or social media platforms.

## software functional requirements
1. The system shall allow users to import and select a photo from their device.

2. The system shall provide options for users to choose the shape of the sticker from predefined shapes.

3. The system shall allow users to set the size of the sticker using adjustable parameters.

4. The system shall enable users to add customizable text to the sticker, including font selection and color options.

5. The system shall provide users with a variety of decorative elements that can be added to the sticker.

6. The system shall include a cropping tool that allows users to crop the imported photo.

7. The system shall provide a resizing tool that allows users to resize the imported photo.

8. The system shall offer effects that can be applied to the photo, such as filters and adjustments.

9. The system shall allow users to save the created sticker as a transparent PNG file.
