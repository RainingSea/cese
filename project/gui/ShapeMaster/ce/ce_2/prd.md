## general overview of the project
ShapeMaster is a graphics software application that focuses on creating and editing geometric shapes. It provides a variety of tools for drawing and manipulating shapes, including rectangles, circles, triangles, polygons, and more. Users can easily customize the size, position, and style of the shapes, and apply colors, gradients, and patterns. ShapeMaster also offers features such as aligning, grouping, and arranging shapes for precise composition. This software is designed to be user-friendly, allowing both professional designers and beginners to easily create and edit geometric-based graphics.

## software functional requirements
1. The system shall allow users to create geometric shapes, including rectangles, circles, triangles, and polygons.

2. The system shall provide functionality for users to edit geometric shapes, including resizing and repositioning.

3. The system shall enable users to customize shape styles, including the application of colors, gradients, and patterns.

4. The system shall provide tools for aligning shapes to ensure precise composition.

5. The system shall allow users to group multiple shapes together for easier manipulation.

6. The system shall provide options for arranging shapes, including bringing shapes to the front or sending them to the back.
