**Case: `test_registration`**

**Pseudocode:**
```plaintext
ROUTE '/register' (GET)
    RENDER registration.html
END ROUTE

ROUTE '/register' (POST)
    RECEIVE username and password from request
    CALL user_manager.register(username, password)
    IF registration SUCCESS
        FLASH confirmation message
        REDIRECT to '/login'
    ELSE
        FLASH error message
    ENDIF
END ROUTE

// FILE: user_manager.py
CLASS UserManager:
    FUNCTION register(username: str, password: str) -> bool
        IF username already in self.users
            RETURN False
        ENDIF
        APPEND username and password to users_file
        ADD username to self.users
        RETURN True
    END FUNCTION
END CLASS
```

**Key Functionality:**
- This implementation handles user registration by verifying if the username already exists, appending new user data to a text file, and updating the in-memory user list.
- It integrates file handling for persistent storage of user information alongside Flask's routing and rendering.
