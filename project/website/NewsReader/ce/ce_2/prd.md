## general overview of the project
Develop a web application named 'News Reader' that allows users to read and stay updated on the latest news articles from various sources. The application offers a clean, user-friendly interface and personalized news feeds based on user interests.

## software functional requirements
1. **User Registration**:  
   - The system shall provide a Registration Page where users can create an account by entering a username and password.  
   - The system shall store user credentials in a local text file for authentication.  

2. **User Login**:  
   - The system shall provide a Login Page where users can log in using their registered username and password.  
   - The system shall validate credentials against stored data in the local text file.  

3. **News Category Browsing**:  
   - The system shall display a Dashboard Page where users can browse news articles categorized under topics such as politics, sports, and entertainment.  

4. **Article Search**:  
   - The system shall allow users to search for specific topics or keywords to retrieve relevant articles from the news feed.  

5. **News Feed Display**:  
   - The system shall display a list of news articles on the Dashboard Page, showing the headline, summary, and source of each article.  

6. **Article Details View**:  
   - The system shall provide an Article Details Page where users can view the full text of an article upon clicking it from the news feed.  

7. **User Logout**:  
   - The system shall allow users to log out of their account, redirecting them back to the Login Page.
