## general overview of the project
Develop a web application called 'Task_Manager' that allows users to create, manage, and track their tasks, using a local text file for data storage.

## software functional requirements
1. **User Authentication**
   - The system shall provide a login page where users can enter their username and password to access the application.
   - The system shall allow users to navigate to a registration page from the login page.

2. **User Registration**
   - The system shall provide a registration page where users can create a new account by entering a username, password, and email.
   - The system shall validate the input data and store the new account information in a local text file.

3. **Task Management**
   - The system shall display a list of tasks for the logged-in user on the home page.
   - The system shall allow users to add new tasks by entering a task description and due date on the home page.
   - The system shall provide a "Remove Task" button for each task, allowing users to delete tasks from the list.

4. **Navigation**
   - The system shall provide a "Back to Login" button on the home page to allow users to return to the login page.
