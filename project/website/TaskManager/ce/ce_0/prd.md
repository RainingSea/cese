## general overview of the project
Develop a web application called 'Task_Manager' that allows users to create, manage, and track their tasks, using a local text file for data storage.

## software functional requirements
1. **User Login**
   - The system shall provide a login page where users can enter their username and password to log in.

2. **User Registration**
   - The system shall provide a registration page where users can create a new account by entering a username, password, and email.

3. **Task List View**
   - The system shall display a list of tasks associated with the logged-in user on the home page.

4. **Add New Task**
   - The system shall allow users to add new tasks by entering a task description and due date on the home page.

5. **Remove Task**
   - The system shall allow users to remove tasks from their task list by clicking the associated "Remove Task" button for each task.

6. **Navigation to Login Page**
   - The system shall provide a "Back to Login" button on the home page that navigates users back to the login page.
