## general overview of the project
Develop a web application 'TravelRecommender' that provides personalized recommendations for travel destinations based on user preferences, such as budget, activities, and preferred climate.

## software functional requirements
1. **User Registration**:  
   - The system shall provide a Registration Page where users can create an account by entering a username and password.  
   - The system shall store user credentials in a local text file for authentication purposes.  

2. **User Login**:  
   - The system shall provide a Login Page where users can log in by entering their registered username and password.  
   - The system shall validate the entered credentials against stored data in the local text file.  

3. **Travel Preferences Input**:  
   - The system shall allow users to input their travel preferences, including budget, preferred activities, and desired climate.  
   - The system shall store these preferences in a local text file for future reference.  

4. **Personalized Destination Recommendations**:  
   - The system shall generate a list of travel destinations that match the user's preferences based on predefined criteria.  
   - The system shall retrieve destination details from a local text file containing information about activities, climate, and costs.  

5. **Destination Details View**:  
   - The system shall display detailed information about each recommended destination, including popular activities, climate, and travel costs.  

6. **Favorite Destinations**:  
   - The system shall allow users to save their favorite destinations to a list stored in a local text file.  

7. **User Logout**:  
   - The system shall provide a logout option that terminates the user session and returns the user to the Login Page.
