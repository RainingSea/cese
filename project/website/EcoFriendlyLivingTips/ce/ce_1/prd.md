## general overview of the project
Develop a comprehensive web application named 'EcoFriendlyLivingTips' that provides users with valuable tips and resources for adopting a more environmentally friendly lifestyle. Note that the website should start from the login page.

## software functional requirements
1. Users shall be able to log in to access personalized content.
2. Users shall be able to create a new account.
3. Users shall be able to view an introduction to eco-friendly living and navigate to key features.
4. Users shall be able to view eco-friendly living tips and submit new tips.
5. Users shall be able to access external resources and add new resources.
6. Users shall be able to view and participate in the community forum.
7. Users shall be able to view and update their profile information, and log out.
8. Users shall be able to contact the support team through a contact form.
