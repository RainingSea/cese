Develop a web application named 'DailyHealthTips' that provides users with daily health tips, allowing them to receive advice and information about maintaining a healthy lifestyle, using Python as the development language. Note that the website should start from the login page.

## software functional requirements
1. Users shall be able to log in to their accounts.
2. Users shall be able to navigate to the Registration Page via the Register here link if they do not have an account.
3. Users shall be redirected to the archives page by default after login.
4. Users shall be able to view the current daily health tip and navigate to previous or next tips.
5. Users shall be able to view all historical daily health tips through a tips archive.
6. Users shall be able to search for specific tips from the tips archive.
7. Users shall be able to submit feedback on the daily health tips.
