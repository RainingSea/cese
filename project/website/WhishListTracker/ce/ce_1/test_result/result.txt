   - **Problem:** User registration does not currently perform any validation checks to avoid duplicate usernames, which could lead to inconsistencies in user management.
     - **Suggestions:** Modify the `register` method in the `User` class to check if the username already exists in `users.txt` before adding a new user. If the username exists, provide feedback to the user on the registration page.

3. **Session Management and Logout**
   - **Problem:** The application does not ensure that the session is cleared properly during logout, which could lead to issues with session persistence or unexpected behavior.
     - **Suggestions:** Enhance the `logout` function in `main.py` to not only remove the username from the session but also clear any related session variables to ensure a complete logout process.

4. **Error Handling**
   - **Problem:** The current implementation does not adequately handle errors, such as failed login attempts or file handling exceptions when reading/writing `users.txt` or `wishlist.txt`.
