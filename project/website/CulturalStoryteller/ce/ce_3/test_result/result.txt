- **Related Code**:

  The `login` method looks for an input element by the name 'username'. If the page isn¡¯t fully loaded, it throws an exception.

- **Resolution**: Add a wait mechanism to ensure the page is completely loaded before trying to access elements. You can use `WebDriverWait` from Selenium to wait until the element is present:
    ```python
    from selenium.webdriver.common.by import By
    from selenium.webdriver.support.ui import WebDriverWait
    from selenium.webdriver.support import expected_conditions as EC

    def login(self, username, password):
        WebDriverWait(self.driver, 10).until(
            EC.presence_of_element_located((By.NAME, "username"))
        )
        self.driver.find_element(By.NAME, 'username').send_keys(username)
        self.driver.find_element(By.NAME, 'password').send_keys(password)
        self.driver.find_element(By.XPATH, '//button[text()="Login"]').click()
    ```
