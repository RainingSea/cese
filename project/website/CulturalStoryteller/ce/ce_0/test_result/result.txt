- When submitting the login form from `login.html`, it directs to `/dashboard` using the POST method but there is no route defined for POST on `/dashboard`.
  
**Resolution:**
- Update the `login()` function to handle POST requests, verify the credentials, and redirect accordingly.

```python
@app.route('/', methods=['GET', 'POST'])
def login():
    if request.method == 'POST':
        username = request.form['username']
        password = request.form['password']
        if user_manager.login(username, password):
            session['username'] = username  # Set session
            return redirect(url_for('dashboard'))
        return "Invalid credentials"
    return render_template('login.html')
```
