## general overview of the project
Develop a web application named 'BookWorm Search' that enables users to search for books in their personal libraries or online with ease. The application will provide a simple interface for efficient book search and management.

## software functional requirements
1. **User Registration**: The system shall allow users to register for an account by entering a username and password on the Registration Page.
2. **User Login**: The system shall allow users to log in to their account by entering a username and password on the Login Page.
3. **Book Search**: The system shall provide a search bar on the Dashboard Page where users can search for books by title, author, or keywords.
4. **Search Results Display**: The system shall display a list of matching book results with relevant details such as title, author, and summary.
5. **Book Details View**: The system shall allow users to click on a book from the search results to view detailed information, including description and author details, on the Book Details Page.
6. **Add to Reading List**: The system shall provide an 'Add to Reading List' button on the Book Details Page, allowing users to add books to their personal reading list.
7. **Reading List Management**: The system shall provide a dedicated Reading List Page where users can view and manage their reading list.
8. **User Logout**: The system shall allow users to log out of their account, returning them to the Login Page.
