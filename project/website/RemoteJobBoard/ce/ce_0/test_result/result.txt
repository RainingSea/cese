- **Issue:** Concurrent requests could corrupt files (e.g., two users registering simultaneously).

    ```python
    import tempfile
    def update_file(filename, content):
        with tempfile.NamedTemporaryFile('w', delete=False) as tmp:
            tmp.write(content)
            tmp.flush()
            os.replace(tmp.name, filename)
    ```
