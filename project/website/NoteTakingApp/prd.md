## general overview of the project
Develop a comprehensive web application called 'NoteTakingApp' that enables users to create, view, and manage notes without the need for a SQL database, leveraging Python and storing data in local text files.

## software functional requirements
1. Users shall be able to log in by entering a username and password on the Login Page.
2. Users shall be able to navigate to the Registration Page from the Login Page via the Register link.
3. Users shall be able to register by providing a username, password, and confirming the password on the Registration Page.
4. Users shall be able to view a list of their notes on the Dashboard Page.
5. Users shall be able to add a new note by navigating to the Add Note Page and entering a title and content.
6. Users shall be able to save or discard a newly created note on the Add Note Page.
7. Users shall be able to view the details of a note by navigating to the View Note Page from the Dashboard.
8. Users shall be able to edit the note on the View Note Page and save the changes.
9. Users shall be able to delete the note on the View Note Page.
10. Users shall be able to search for a note by title on the Search Note Page.
11. Users shall be able to view the search results on the Search Note Page.
12. Users shall be able to navigate back to the Dashboard Page from the Search Note Page.
13. Users shall be able to log out from the Dashboard Page.
