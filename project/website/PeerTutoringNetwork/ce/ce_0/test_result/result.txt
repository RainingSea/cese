### **2. Summary of Failed/Error Test Cases & Guidance**  

#### **1. Static Page Title Issue (Affects Multiple Tests)**  
- **Tests Affected:** `test_user_login`, `test_user_registration`, `test_access_dashboard`, `test_user_logout`  
- **Error:** Title remains "Peer Tutoring App" instead of dynamically updating.  
- **Root Cause:** `base.html` has a hardcoded `<title>`.  
- **Guidance:**  
  - Modify `base.html` to support dynamic titles:  
    ```html
    <title>Peer Tutoring - {% block title %}{% endblock %}</title>
    ```
  - Update child templates (e.g., `dashboard.html`, `login.html`) to include:  
    ```html
    {% block title %}Dashboard{% endblock %}
    ```

#### **2. Navigation Issues (Tutors/Profile/Request Pages Not Loading Properly)**  
- **Tests Affected:** `test_view_available_tutors`, `test_access_profile_page`, `test_request_tutoring`  
- **Error:** Pages not rendering expected content (e.g., "Available Tutors" missing).  
- **Root Cause:**  
  - Possible misconfigured routes or template rendering issues.  
  - **Example:** `tutors.html` may not be correctly rendered in `/tutors` route.  
- **Guidance:**  
  - Verify Flask route handlers (e.g., `/tutors`, `/profile`, `/request`) are correctly returning `render_template()`.  
  - Ensure template inheritance (`{% extends "base.html" %}`) is properly structured.  
  - Debug by manually checking rendered HTML in browser.  

#### **3. Contact Page Accessibility Issue**  
- **Test Affected:** `test_contact_support`  
- **Error:** "Contact" link not found when not logged in.  
- **Root Cause:**  
  - `base.html` hides "Contact" link inside `{% if 'username' in session %}` block.  
- **Guidance:**  
  - Move "Contact" link outside the login-restricted block in `base.html`.  
  - Ensure `/contact` route does not require authentication.  

#### **4. Missing Cancel Request Functionality**  
- **Test Affected:** `test_cancel_tutoring_request`  
- **Error:** Explicit failure due to unimplemented feature.  
- **Root Cause:**  
  - No UI for canceling requests in `profile.html` or backend logic in `RequestManager`.  
- **Guidance:**  
  - Add a "Cancel" button in `profile.html` for pending requests.  
  - Extend `RequestManager.cancel_request()` to handle UI interactions.  

### **Key Takeaways for Future Development**  
1. **Dynamic Page Titles:** Always use template blocks for titles to avoid hardcoding.  
2. **Route & Template Validation:** Ensure routes correctly render templates and verify navigation.  
3. **Authentication Logic:** Review which pages should be public (e.g., Contact) and adjust `base.html` accordingly.  
4. **Feature Completeness:** Implement all planned UI interactions (e.g., canceling requests) before testing.
