## general overview of the project
The objective of the PeerTutoringNetwork task is to develop a comprehensive web application using Python that facilitates peer-to-peer tutoring while storing all necessary information locally in text files.

## software functional requirements
1. Users shall be able to log in using their username and password on the login page.
2. Users shall be able to navigate to the registration page to create a new account.
3. Users shall be able to create a new account by entering a username, password, and email on the registration page.
4. Users shall be able to access a dashboard after successfully logging in.
5. Users shall be able to view available tutors by clicking the "View Tutors" button on the dashboard.
6. Users shall be able to request tutoring by filling out a form with the subject, details, and preferred date of tutoring.
7. Users shall be able to access their profile page to view their username and email.
8. Users shall be able to log out from the application via the logout link on the dashboard or profile page.
9. Users shall be able to contact the support team by filling out a contact form on the "Contact Us" page, including their name, email, and message.
10. Users shall be able to cancel a tutoring request and return to the dashboard from the request tutoring page.
