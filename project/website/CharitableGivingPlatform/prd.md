## general overview of the project
Develop a web application named 'CharitableGivingPlatform' that enables users to manage and contribute to charitable causes seamlessly using Python and local storage. Note that the website should start from the login page.

## software functional requirements
1. **User Login**: Users shall be able to log in to their accounts on the Login Page by entering a username and password.
2. **User Registration**: Users shall be able to navigate to the Registration Page via the Register here link if they do not have an account.
3. **Charity List View**: Users shall be able to view a list of available charities on the Dashboard Page.
4. **Charity Details**: Users shall be able to navigate to the Charity Details Page to see detailed information about each charity, including its mission and ongoing projects.
5. **Contribution History**: Users shall be able to view their own contribution history on the Dashboard Page.
6. **Donation Functionality**: Users shall be able to donate to a charity by entering a donation amount and clicking the donate button on the Charity Details Page.
7. **User Logout**: Users shall be able to log out of their account on the Dashboard Page, returning to the Login Page.
8. **Navigation Back to Dashboard**: Users shall be able to navigate back to the Dashboard from the Charity Details Page using a back button.
9. **Charity Selection**: Users shall be able to select and view detailed information about a specific charity by clicking on a charity’s 'Details' button on the Dashboard Page.
