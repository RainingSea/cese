- **Related Code in `main.py`**:
  ```python
  @app.route('/')
  def login():
      return render_template('login.html')
  ```
  - Here, the `login` route is defined with `GET` method but without a corresponding `POST` implementation, which is required for form submission.
  
- **Solution**:
  - You need to define a `POST` method for the login route to handle user login and redirection appropriately.

  ```python
  @app.route('/', methods=['GET', 'POST'])
  def login():
      if request.method == 'POST':
          username = request.form['username']
          password = request.form['password']
          if authenticate(username, password):  # Assuming you introduce an authenticate function
              return redirect(url_for('home'))
      return render_template('login.html')
  ```
