## general overview of the project
Develop an Online Library Management System that allows users to manage and access library resources efficiently without utilizing SQL for data storage.

## software functional requirements
1. **User Authentication**  
   - Users shall be able to log in to their accounts using valid credentials.  
   - Users shall be able to register a new account by providing necessary details.  

2. **Dashboard Navigation**  
   - Users shall be able to view the dashboard upon successful login.  
   - Users shall be able to navigate to different sections, including book management, user management, and search books.  

3. **Book Management**  
   - Users shall be able to add new books by entering book details (e.g., title, author, ISBN).  
   - Users shall be able to delete books from the library.  
   - Users shall be able to view the list of all available books.  

4. **User Management**  
   - Users shall be able to add new user accounts with appropriate details.  
   - Users shall be able to view the list of all registered users.  

5. **Book Search**  
   - Users shall be able to search for books in the library using keywords (e.g., title, author).  

6. **Logout Functionality**  
   - Users shall be able to log out of their account securely.  
   - Upon logout, users shall be redirected to the login page or home page.  

7. **Data Storage**  
   - All data (books, users) shall be stored in separate `.txt` files.  
   - The system shall read and write data to these files for persistence.
