## general overview of the project
Develop an Online Library Management System that allows users to manage and access library resources efficiently without utilizing SQL for data storage.

## software functional requirements
1. User Authentication
   - The system shall allow users to log in to their accounts using a username and password.
   - The system shall provide a registration feature for new users to create an account.

2. Dashboard Navigation
   - The system shall display a dashboard upon successful login.
   - The dashboard shall provide navigation options to different sections, including book management, user management, and book search.

3. Book Management
   - The system shall allow users to add new books to the library.
   - The system shall allow users to delete existing books from the library.
   - The system shall provide a feature to view the list of all books available in the library.

4. User Management
   - The system shall allow users to add new user accounts.
   - The system shall provide a feature to view the list of all users registered in the system.

5. Book Search
   - The system shall allow users to search for books in the library using various search criteria.

6. User Logout
   - The system shall allow users to log out of their accounts.
   - Upon logging out, users shall be redirected to the login page.
