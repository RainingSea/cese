## general overview of the project
Develop a web application named 'Trip Saver' that helps users find the most cost-effective and time-efficient mode of transportation for their trips.

## software functional requirements
1. **User Registration**: The system shall allow users to register for an account by entering a username and password on the Registration Page.
2. **User Login**: The system shall allow users to log in to their account by entering their username and password on the Login Page.
3. **Trip Details Input**: The system shall allow users to input trip details, including starting point, destination, and travel date.
4. **Transportation Suggestions**: The system shall provide suggestions for the most cost-effective and time-efficient transportation options, including public transport, ride-sharing, and walking.
5. **Cost and Time Estimation**: The system shall display estimated costs and travel times for each transportation option.
6. **Comparison of Options**: The system shall allow users to compare different transportation options based on distance, cost, and time.
7. **Save Preferences**: The system shall allow users to save their preferred transportation options for future reference.
8. **User Logout**: The system shall allow users to log out of their account, returning them to the Login Page.
