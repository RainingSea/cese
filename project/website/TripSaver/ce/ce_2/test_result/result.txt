  In the `register` method, there is no check for whether the username already exists. The application simply appends the new user to the list and writes to `users.txt`. As a result, if a username already exists, it gets added again without any error or warning, leading to a logical failure in the assertion test.

- **Recommendation**:
  Implement duplicate username checking during registration:
  ```python
  def register(self, username: str, password: str):
      if any(user.username == username for user in self.users):
          raise ValueError("username is already taken")
      new_user = User(username, password)
      self.users.append(new_user)
      with open('users.txt', 'a') as file:
          file.write(f"{username}|{password}\n")
  ```
