### Problem 2: Lack of Error Handling and User Feedback Mechanisms
- **Description:** 
  The application currently provides minimal feedback on failures during registration or trip input (e.g., incomplete form submission).
- **Suggestions:** 
  - Introduce proper error handling to inform users about failed operations through user-friendly messages. ### Problem 3: Inadequate Session Handling
- **Description:** 
  The application requires that the user session maintain state effectively through the application flow, particularly through navigating back to the trip input or options pages.
- **Suggestions:** 
  - Ensure that session checks are in place before rendering pages that require a logged-in user. For instance, redirect users to the login page if they navigate to `/trip_input` without being authenticated.

  - **Improved Navigation:** Consider headers or footers with navigational links to improve the navigation experience.

- The local text files are sufficient for the current implementation; however, consider the following:
  - Introduce better file structure (like separating user data and trip data more distinctly) if the complexity of data grows. 
  - Implement a rollback or recovery mechanism for data if the file overwrites happen during user registration or trip input.

### Data Structures:
