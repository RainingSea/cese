## general overview of the project
Develop a web application called 'Task_Manager' that allows users to create, manage, and track their tasks, using a local text file for data storage.

## software functional requirements
1. Users shall be able to log in using their username and password on the login page.
2. Users shall be able to navigate to the registration page to create a new account.
3. Users shall be able to create a new account by entering a username, password, and email on the registration page.
4. Users shall be able to view a list of their tasks on the home page.
5. Users shall be able to add new tasks by entering a task description and due date on the home page.
6. Users shall be able to remove tasks from the task list by clicking the associated "Remove Task" button for each task.
7. Users shall be able to navigate back to the login page from the home page by clicking the "Back to Login" button.
