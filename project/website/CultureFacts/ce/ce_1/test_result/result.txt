- **UI Design:** Improving the navigation between pages can enhance the user experience. For example, enabling users to return to the dashboard easily from any page using a common header or footer with navigation links.

- **Data Storage:** While using text files is workable for small projects, consider transitioning to structured data (e.g., JSON format), which could allow for future feature expansions like adding more culture attributes or facilitating more complex queries without losing context.
