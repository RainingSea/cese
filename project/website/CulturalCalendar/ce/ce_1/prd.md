## general overview of the project
Develop a web application named 'The Cultural Calendar' that provides users with a curated collection of cultural events, festivals, and celebrations from around the world. The application allows users to explore event details and set reminders for events they are interested in.

## software functional requirements
1. **User Registration**: Users shall be able to register for an account on the Registration Page by entering a username and password. The system shall store user credentials in a local text file.
2. **User Login**: Users shall be able to log in to their account on the Login Page by entering a username and password. The system shall validate credentials against stored data.
3. **Event Display**: Users shall be able to view a calendar or list of upcoming cultural events on the Dashboard Page. Event data shall be retrieved from a local text file.
4. **Event Details**: Users shall be able to click on an event to view detailed information, including the significance, history, and location of the event, on the Event Details Page.
5. **Event Search**: Users shall be able to search for events by keywords, categories, or dates. The system shall filter events based on user input.
6. **Set Reminder**: Users shall be able to add events to their personal list of reminders by clicking a 'Set Reminder' button on the Event Details Page. The system shall store reminders in a local text file.
7. **Manage Reminders**: Users shall be able to view and manage their list of reminders on a dedicated Reminders Page. The system shall allow users to delete reminders.
8. **User Logout**: Users shall be able to log out of their account, returning to the Login Page. The system shall terminate the user session.
