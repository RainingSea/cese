```pseudocode
CLASS CartManager
    FUNCTION add_to_cart(username: STRING, product_id: INT)
        IF username NOT IN carts
            carts[username] = []
        ENDIF
        IF product_id NOT IN carts[username]
            carts[username].APPEND(product_id)
            CALL save_cart()
        ENDIF
    END FUNCTION

    FUNCTION save_cart()
        OPEN 'cart.txt' FOR WRITING AS file
            FOR EACH username, product_ids IN carts
                WRITE username + "|" + JOIN(product_ids, ",") + "\n" TO file
            ENDFOR
        CLOSE file
    END FUNCTION
END CLASS
```
**Key Functionality**: This functionality allows users to add products to their shopping cart. It checks if the user already has a cart; if not, it creates one. It also ensures that the same product cannot be added multiple times.

```pseudocode
    END FUNCTION
END CLASS
```
