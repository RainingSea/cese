**3. Add Product to Cart (test_add_product_to_cart)**

```plaintext
CLASS CartManager
    FUNCTION __init__(filename)
        SET self.filename = filename
        SET self.carts = {}

    FUNCTION add_to_cart(username, product_id)
        IF username NOT IN self.carts
            SET self.carts[username] = []
        IF product_id NOT IN self.carts[username]
            APPEND product_id TO self.carts[username]
            CALL self.save_cart()

    FUNCTION save_cart()
        OPEN self.filename AS file
        FOR EACH username, product_ids IN self.carts
            WRITE username + '|' + ','.join(product_ids) TO file
        END FOR
END CLASS

ROUTE /add_to_cart/<product_id>
    IF 'username' IN session
        CALL cart_manager.add_to_cart(session['username'], product_id)
    REDIRECT to '/product_listing'
```

**Key Functionality:**
- The `CartManager` class manages the shopping cart for users, allowing products to be added and saved to a file.
- The route for adding to the cart checks if the user is logged in and adds the product to their cart.
